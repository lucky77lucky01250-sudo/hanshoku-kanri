# 紹介資料

繁殖牛管理アプリを人に紹介するための資料。**用途別に2種類**ある。

| ファイル | 渡す相手 | 中身 |
|---|---|---|
| `繁殖牛管理_導入案内` | 繁殖農家さん | 「こんなこと、ありませんか」→ 繁殖サイクル4段階 → できること → 実績 → はじめかた。専門用語なし・現場目線 |
| `繁殖牛管理_実績紹介` | 発注者・経営者（案件獲得用） | 解決した課題 → 設計上の判断3つ → 機能 → 技術構成 → 運用実績 → 現場フィードバックで直した6件 |

各A4・4ページ。

## ファイルの関係（重要）

**`.html` が原本。`.pdf` はそこから生成したもの。**
内容を直すときは必ず `.html` を編集し、下のコマンドでPDFを作り直す。PDFを直接編集しない。

```bash
cd docs && "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --no-pdf-header-footer --virtual-time-budget=12000 --print-to-pdf="$PWD/繁殖牛管理_導入案内.pdf" "file://$PWD/繁殖牛管理_導入案内.html"
```

※ Chrome はPDFを書き出したあと終了しないことがある。ファイルができていれば `pkill -f "Google Chrome.*headless"` で止めてよい。

## 記載している数字の根拠（2026-08-30時点）

対外的な公称は **「2戸に導入、実際に51頭を管理中」** で統一する。

| 数字 | 内訳 |
|---|---|
| 2戸 | 実際にデータを入力した農家。登録アカウントは他にもあるが入力ゼロなので数えない |
| 51頭 | 34頭 + 17頭。本人アカウントのテスト5頭は含めない |
| 55件 | 記録された種付け（実績紹介のみ） |
| 23回 | 初回リリース後の改善コミット数（実績紹介のみ） |

数字を更新するときは、必ず本番データを見直してから書き換える。

## 更新するときの注意

- **このリポジトリは公開設定。** 中身を書き換えたら、公開して問題ない内容か毎回確認する
- 現状、APIキー・接続情報・利用者の個人情報は含まれていない。連絡先は開発者本人のもののみ
- 実績値は生きた数字なので、**古いまま配らない**
- Google Drive 側にも同じものを複製してある。更新したら両方を揃える

## デザインについて

アプリ自身が通知メールで使っている深緑 `#1b4332` を基調に、和牛の黄色い耳標から採った `#c99503` をアクセントにしている。
書体は見出しが Zen Old Mincho、本文が Zen Kaku Gothic New、数字が Roboto Mono（すべてGoogle Fonts）。
ダークモードにも対応済み。
